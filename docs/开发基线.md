# 离线剪辑开发基线

更新日期：2026-11-08。用户确认范围为完整 01–15 项。本次完成开发准备、核心模型、时间线工作台、逆向面板 Dock、本机 APK 构建验证和第一版离线 MP4/MP3 导出。详见 [交互重构说明](交互重构说明.md)。

## 第一性原理

剪辑是一份可重复执行的媒体变换描述。原始素材保持不变；项目保存素材引用、截取区间、时间映射、画面变换和轨道顺序。预览与成片必须最终执行同一份描述。

1. **素材**：视频、图片、音频各自有本地文件、类型和时长。准备版通过系统文件选择器复制到应用私有目录，之后操作不依赖文件提供方的持续可用性。图片默认持续 5 秒，当前界面只能缩短，延长图片时长尚待实现。
2. **源时间与项目时间**：核心统一用微秒，区间采用 `[in, out)`。普通变速 `输出时长 = (out-in)/speed`。播放器适配层才转换为毫秒。
3. **曲线变速**：新实现将速度控制点定义在归一化源时间上；各段速度线性变化。输出时间必须积分 `dt=ds/v(s)`，seek 则反求源时间。这里是新工程的明确定义，未证明与原引擎的曲线插值相同。
4. **倒放**：从所选源区间的末尾反向取样；不能只把播放器速度改成负数。0.3.0 导出按源时间逆向取帧并重新编码，音频同样逆向取样；预览尚未同步实现，需要真机核验性能与音画同步。
5. **画面变换**：中心坐标系，先缩放和旋转，再按输出画布尺寸进行归一化平移。预览采用 Android View 变换，导出采用独立画布渲染，仍需验证裁切、像素宽高比和素材方向元数据的一致性。
6. **时间线**：主画面顺序拼接，音频使用独立叠加轨。片段变速后重新计算后续片段起点。核心支持音轨起点，准备版导入音频统一从零开始，导出阶段已有混音执行器，预览尚未接入；界面提供缩略图、固定播放头、双指缩放、两端裁剪和长按排序。

## 开发顺序

1. 将准备版安装到 Android 8.0 以上设备，验证启动、三类导入、草稿恢复、片段预览和编辑。
2. 接入共享媒体执行层，先完善普通速度下的视频/图片连续预览、单音轨播放和基础 MP4 成片。
3. 让预览与导出共用变换与时间映射，使用有可见帧号和音频节拍的短素材验证。
4. 接入曲线变速和倒放：按 GOP 解码、有限内存缓存、取消与磁盘预算；验证曲线时长、逆序帧及音轨同步。保持音高的音频重采样单独选型。

## 本机验证

- Java 21.0.10、Android API 35 平台、Build Tools 35.0.0 已可用。
- 构建工具在本工程 `.tools` 下；核心依赖标准 Java，应用依赖 Android SDK，MP3 导出使用 Jump3r 1.0.5；依赖、对应源码和许可证通过校验后离线打包。
- 通过 `javac → D8 → AAPT2 → zipalign → apksigner` 完成 APK 编译、打包和签名；不要求 Gradle。
- `tools/test-core.ps1`：1,418 个断言通过，包括独立数值积分对照、倒放边界、半开区间、轨道定位、不可变快照、损坏草稿拒绝，以及正向/倒放分割连续性、裁剪边界和独立音轨保留。
- `tools/test-export.ps1`：真实编码并逐帧检查 128/192/320 kbps MP3 的格式、采样率和时长；尚未替代真机播放验收。
- APK 签名 v2/v3 验证通过；清单无 INTERNET 权限。
- ADB 设备列表为空，未做安装或真机运行；构建成功不等于功能验收完成。
