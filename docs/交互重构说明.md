# 剪漏交互重构说明

更新日期：2026-11-04。

## 设计依据

本轮界面重构来自 `base.apk.1` 的静态逆向证据，不宣称已经动态观察到原应用的每一个手势或像素布局。

- `PanelType` 暴露了 VideoAnimation、Filter、AudioEffect、Text、TextToAudio、Sticker、StickerAnimation、CanvasImage、Music、VideoMask 等面板类型。
- `DockItem` 表明底部工具栏是可显示、可启用、可排序和可多选状态的工具 Dock。
- `VideoController` 暴露了 scale、translateX、translateY、时间范围和归一化偏移等画面参数。
- `VideoSpeedViewModel` 暴露了普通速度、曲线速度和 SpeedPoint 参数组织。

因此剪漏采用“预览区 + 固定播放头时间线 + 片段上下文 Dock + 底部面板”的操作模型。功能入口会先进入项目工作台；只有已经有核心执行能力的操作才会改变草稿或预览。

## 当前操作

- 顶部：切换本地草稿、保存、查看导出状态。
- 预览：视频/图片显示、播放暂停、回到起点、基础连续播放。
- 时间线：点击或拖动定位、双指缩放、拖动片段两端裁剪、长按后拖动排序。
- 片段工具：素材导入、分割、删除、普通变速、曲线/倒放参数保存、缩放/旋转/平移、精确裁剪、项目素材列表。
- 扩展 Dock：动画、滤镜、音效、文字/自动字幕、贴纸、画布/蒙版。它们已经按逆向面板体系布置，面板内的未完成选项标注“开发中”，暂不可操作。

## 能力边界

当前真实可执行的是本地导入、草稿持久化、时间线编排、普通恒速视频/图片基础预览、定位、裁剪、分割、删除、排序和画面 View 变换。

以下内容仍是参数或交互骨架：曲线变速实时取帧、倒放、音频混音、滤镜、动画、文字/自动字幕、贴纸、蒙版，以及 MP4 编码导出。曲线和倒放只保存项目描述，界面会明确提示，避免把普通预览误认为已经生效。

## 第一性原理约束

原始媒体保持不变，项目只保存素材引用、半开时间区间 `[in, out)`、速度映射、倒放标记、画面变换和轨道顺序。后续媒体执行层必须同时服务预览和导出，不能为两个路径各写一套规则。
