## 本机构建

在本目录使用 Windows PowerShell，要求完整 JDK 21。

```powershell
# 首次安装官方 Android SDK 归档（下载并按官方元数据校验 SHA-1）
.\tools\setup-android.ps1 -IncludeAdb
# 测试纯 Java 核心
.\tools\test-core.ps1
# 用官方 SDK 工具直接构建及签名，无需 Gradle
.\tools\build-apk.ps1
```

输出：`build/jianlou-dev.apk`。应用名为「剪漏」，桌面图标使用用户提供的 `android_app_icon_assets.zip`，是戴墨镜的场记板配紫色剪刀的恶搞风格图标。构建安装工具需要联网下载，安装完本机依赖后可断网重新构建。应用未声明 INTERNET 权限，不使用云端编辑接口；首次系统选择器可能显示云提供方，只有成功复制到私有目录的素材才成为本地项目素材。

开发包包名为 `com.example.offlineeditor`，最低 Android 8.0（API 26），target API 35。签名密钥在 `.tools/debug.keystore`，密码为标准开发密码，仅供开发测试。不要用此密钥发布正式版本。

素材导入为应用内独立副本，单文件上限 2 GiB；准备版没有孤立素材清理界面，卸载会清除所有项目与副本。导入后默认保存工作草稿；新建/切换项目时归档当前草稿。

## 手工验收

1. 安装 APK，确认可启动；导入一个短视频、一张图片和一段音频。
2. 在缩略图时间线上点击或拖动定位，双指缩放时间线，拖动片段两端裁剪，长按片段后拖动排序。
3. 选择视频，播放、暂停、拖动定位；裁剪为中间一段，设为 2 倍速。
4. 修改缩放、旋转和平移，检查显示；移动片段，保存并重新启动。
5. 新建并切换草稿，确认旧草稿能恢复。
6. 保存曲线/倒放参数，确认预览明确提示尚未接入，不能将普通播放误认为倒放效果。

现阶段音频导入仅验证素材与轨道数据，不能用音轨混音或导出验收。系统播放器由 40ms UI 轮询协助推进片段，仍不是帧精确剪辑。顶部“导出”目前只提供状态说明和保存草稿，不生成 MP4。
