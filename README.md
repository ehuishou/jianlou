# 剪漏：离线剪辑准备版

公开仓库：<https://github.com/ehuishou/jianlou>

版本：`0.3.0-export`
本版本新增离线 MP4/MP3 导出；APK 构建后会输出对应 SHA-256。

源码、构建脚本和开发文档在 GitHub 公开仓库维护。APK 分发与 GitHub 版本管理独立进行。

范围：原功能清单 01–15。当前是可构建的 Android 离线剪辑工作台，包含本地导入、项目草稿、缩略图时间线、片段上下文工具、基础连续预览、参数编辑、时间线核心和本地导出。

逆向证据与交互重构说明见 [开发基线](docs/开发基线.md) 和 [交互重构说明](docs/交互重构说明.md)。APK 尚未在手机上运行验证。

## 本机构建

在本目录使用 Windows PowerShell，要求完整 JDK 21。

```powershell
# 首次安装官方 Android SDK 归档（下载并按官方元数据校验 SHA-1）
.\tools\setup-android.ps1 -IncludeAdb
# 首次准备并校验 MP3 编码依赖（之后构建使用离线缓存）
.\tools\setup-export-deps.ps1
# 测试纯 Java 核心
.\tools\test-core.ps1
# 实际编码并检查三种 MP3 码率
.\tools\test-export.ps1
# 用官方 SDK 工具直接构建及签名，无需 Gradle
.\tools\build-apk.ps1
```

输出：`build/jianlou-<versionName>.apk`，本版为 `build/jianlou-0.3.0-export.apk`；使用版本文件名保留已有构建。应用名为「剪漏」，桌面图标使用用户提供的 `android_app_icon_assets.zip`，是戴墨镜的场记板配紫色剪刀的恶搞风格图标。构建安装工具需要联网下载，安装完本机依赖后可断网重新构建。应用未声明 INTERNET 权限，不使用云端编辑接口；首次系统选择器可能显示云提供方，只有成功复制到私有目录的素材才成为本地项目素材。

开发包包名为 `com.example.offlineeditor`，最低 Android 8.0（API 26），target API 35。签名密钥在 `.tools/debug.keystore`，密码为标准开发密码，仅供开发测试。不要用此密钥发布正式版本。

素材导入为应用内独立副本，单文件上限 2 GiB；准备版没有孤立素材清理界面，卸载会清除所有项目与副本。导入后默认保存工作草稿；新建/切换项目时归档当前草稿。

## 手工验收

1. 安装 APK，确认可启动；导入一个短视频、一张图片和一段音频。
2. 在缩略图时间线上点击或拖动定位，双指缩放时间线，拖动片段两端裁剪，长按片段后拖动排序。
3. 选择视频，播放、暂停、拖动定位；裁剪为中间一段，设为 2 倍速。
4. 修改缩放、旋转和平移，检查显示；移动片段，保存并重新启动。
5. 新建并切换草稿，确认旧草稿能恢复。
6. 保存曲线/倒放参数，确认预览明确提示尚未接入，不能将普通播放误认为倒放效果。

## 0.3.0 离线导出

导出面板支持：

- MP4：H.264 视频，有声项目附带 AAC 音轨；短边可选 480、720、1080 像素，比例跟随首段素材；帧率可选 24、25、30、60 fps。
- MP3：44.1 kHz 双声道混音，可选 128、192、320 kbps，使用随 APK 打包的 Jump3r 编码器生成真实 MP3。
- 导出先写入应用私有缓存，成功后通过 Android 文件选择器保存到用户指定位置；失败或取消会清理私有缓存，并尝试删除目标文件（取决于文件提供方是否允许删除）。

导出验收：断网导入带声音短视频，分别导出 MP4 和 MP3；核对裁剪、拼接、画面方向、音画同步及所选参数。再检查图片项目、无声音轨、取消导出和存储不足时的提示。自动字幕、滤镜等预留入口仍未实现。

当前限制：变速会改变音调；纯图片或无声视频不能生成有意义的 MP3；系统编码器或素材解码器不支持时会提示失败；导出期间需要保持页面打开。当前机器没有连接 Android 手机，尚未完成真机兼容性验证。

## 0.2.1 图标修复

桌面入口改为各密度的完整圆角方形 PNG，使用独立资源名，避免 Android 8+ 优先选中旧的自适应图标；移除圆形图标声明。保留用户提供的图案和透明圆角，不再让应用自身的自适应图层放大后裁掉边缘。部分手机桌面会统一图标外形，最终轮廓仍由桌面控制；需在目标手机覆盖安装后确认显示，若仍显示旧图标可移除桌面快捷方式后重新添加。
